# entryplug

**Same task. A different body.**

Entryplug is an agent first embodiment exokernel: a small user space core for
access, operation admission, and evidence. Replaceable task libraries let agents
acquire and maintain physical capabilities from supported sensors, compute, and
actuators.

> Work in progress. Entryplug does not provide a working robot capability yet.

```bash
./entryplug doctor
./entryplug doctor --json
./entryplug test
```
